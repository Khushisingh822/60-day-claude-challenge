# NutriScope — AI-Powered Nutrition Dashboard

**Day 9 of my 60-Day AI Challenge**

NutriScope is a modern nutrition dashboard that helps users track meals, monitor calories and macronutrients, analyze micronutrient intake, and receive AI-inspired nutrition recommendations through a clean SaaS-style interface.

## What it does

* Track calories, protein, carbs, and fat
* Monitor micronutrients
* Log daily meals
* View nutrition analytics with charts
* Get personalized food recommendations
* Analyze potential nutrition gaps
* Plan meals with a simple dashboard

## Tech Stack

* HTML5
* CSS3
* JavaScript
* Chart.js

## Why I Built This

I wanted to combine **AI product thinking, frontend development, and dashboard design** into a single project that feels like a real health-tech startup application.
